# Extension - Expense Tracker

A simple and intuitive expense tracker application built with Node.js and Express.

## Overview

This project provides a user-friendly interface for tracking personal expenses. It helps you monitor your spending habits and manage your finances effectively.

## Features

- Track daily expenses
- Simple and clean UI
- Fast and lightweight
- Easy to use

## Tech Stack

- **Backend**: Node.js with Express
- **Frontend**: HTML, CSS, JavaScript

## Installation

```bash
npm install
```

## Usage

Start the application:

```bash
npm start
```

The application will be available at `http://localhost:3000`

## Project Structure

- `index.js` - Main server file
- `public/` - Static assets and frontend files
