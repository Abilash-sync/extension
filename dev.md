# Development Guide

## Getting Started

This document provides guidance for developing and contributing to this project.

## Prerequisites

- Node.js (v16+)
- npm or yarn

## Installation

```bash
npm install
```

## Running the Development Server

```bash
npm run dev
```

## Building for Production

```bash
npm run build
```

## Testing

```bash
npm test
```

## Project Structure

- `/src` - Source code
- `/public` - Static assets
- `/tests` - Test files
- `/dist` - Build output

## Contributing

Please follow the existing code style and conventions when making changes.
